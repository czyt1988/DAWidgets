<div class="daw-section-head">
<h2>Core Features</h2>
<p>A modern widget supplement solution for Qt desktop applications.</p>
</div>

<div class="daw-card-grid">

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><polyline points="6 9 12 15 18 9"></polyline></svg>
</div>
<h3>Selector</h3>
<p>Multi-tag dropdown selector matching <code>el-select</code>. Filterable, allow-create, default-first-option, two height modes. Includes <code>DAChipsEdit</code>, <code>DAChip</code>, <code>DAFlowLayout</code>.</p>
</div>

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><rect x="3" y="3" width="18" height="6" rx="1"></rect><rect x="3" y="13" width="18" height="8" rx="1"></rect></svg>
</div>
<h3>Collapse</h3>
<p>Collapsible panel container and items matching <code>el-collapse</code>. Accordion mode, animated expand/collapse, custom title and content.</p>
</div>

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="13.5" cy="6.5" r="2.5"></circle><circle cx="19" cy="13" r="2"></circle><circle cx="6" cy="12" r="3"></circle><circle cx="10" cy="20" r="2"></circle></svg>
</div>
<h3>Property Editors</h3>
<p>Property item container + alignment editor, file path selector, time format editor, recent files manager for building property panels.</p>
</div>

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="10"></circle><path d="M12 2a14.5 14.5 0 0 0 0 20 14.5 14.5 0 0 0 0-20"></path><path d="M2 12h20"></path></svg>
</div>
<h3>Color/Pen Editors</h3>
<p>Color grid, palette, color menu, picker button, pen/brush style combo boxes, complete pen/brush/font/shape editing panels.</p>
</div>

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M13 2L3 14h9l-1 8 10-12h-9l1-8z"></path></svg>
</div>
<h3>RAII Cursor Guard</h3>
<p><code>DACursorScoped</code> and <code>DAWaitCursorScoped</code> provide exception-safe cursor management with automatic restoration.</p>
</div>

<div class="daw-card">
<div class="daw-card-icon">
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M12 22s8-4 8-10V5l-8-3-8 3v7c0 6 8 10 8 10z"></path></svg>
</div>
<h3>PIMPL + Dual Compat</h3>
<p>Unified <code>DA_</code> PIMPL macro suite, Qt5/Qt6 compatibility macros, static/shared library dual-mode export. Ready to use.</p>
</div>
